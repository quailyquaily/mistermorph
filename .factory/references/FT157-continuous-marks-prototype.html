FT155 · Fab corner marks: one continuous stroke each

A visual prototype only, not application code. Each of the two marks is one SVG element holding one <path>: a straight arm, the same continuous (Core Animation) corner curve as the button scaled to sit concentric with it, then the other straight arm. There are no border sides, masks, clips or separate segments, so nothing can split at the curve. The button and the marks below come from the same curve function, so the clear gap round the turn stays at 3.94–4.01pt (stroke centre 4.5pt out), where the tangent point and the straight arms carry it unchanged.

Fixed marks (hover / press the button)

Defaults keep FT155's placement: the marks' outer edge 5pt outside the button (stroke centre 4.5pt) and a 1pt muted-foreground hairline. Arm length is measured from the mark's corner point. The curve alone reaches 1.5287 × 12.5 ≈ 19.1pt, so the default 22pt leaves about 3pt of straight run at each open end.

States at actual size: light / dark

As in Fab today, only the button reacts: hover shows the tooltip, a press sinks the button 1pt and softens its shadow, and disabled fades only the button. The marks are sibling views and stay put, so a press shifts the top and bottom gaps by 1pt for its duration. That is existing behavior, unchanged here.

Why it breaks: reported vs FT155 construction vs fix

From 1000019201.png (6×, nearest-neighbour). Left: top-left mark. Right: bottom-right mark.
The two arms come out at different weights and positions, and they step where they meet in the curve.

FT155: a 10pt box with border-l border-t rounded-tl-[3px] corner-squircle. The renderer paints each border side on its own, and the 3pt turn is split between them along the diagonal. Each half is rasterised and snapped separately (a 1pt side on a fractional device-pixel grid), so the halves need not meet (the offset drawn here is exaggerated to show it).

button edge (r 8)mark: one pathBézier handlescurve ↔ straight joins

Fix: one path per mark, M arm → L curve start → C → L → C → L → C → L arm. Every join is tangent-continuous inside one stroke, so there is no seam to rasterise.
