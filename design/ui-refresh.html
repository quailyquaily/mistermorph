The loading state. Idle composer as now; while a task runs, a beam travels its border.APPROVED
IDLE · UNCHANGED
RUNNING · BORDER BEAM
beam
A gradient segment riding the element’s existing 1 px border: clear tail → #2463AE at 72% → #A9CCF5 head. Length 96 px on the composer, 64 px on md/sm buttons, 40 px on xs/xxs.
motion
Clockwise, one lap per 2.3 s, linear, constant speed around the corners (it follows the 2 px radius).
glow
A copy on a 3 px ring, blur 3 px, 25% opacity. Faint by design.
composer
Shown only while the task runs. The send square has already become stop and stays pressable.
reduced motion
The beam rests at the top left (12% along the border).

nsh/GPUI has no CSS masks or offset-path: the beam is a gradient stroke along the rounded-rect path, its dash offset animated, with a blurred copy under it. Build it once as a shared primitive for buttons and the composer.
