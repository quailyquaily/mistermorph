# Runtime 页面设计调整

## 目标与范围

`settings/runtime` 用于确认所选 runtime 是否正常、已运行多久、使用的模型与渠道，以及资源占用。保留现有数据和 Poke 功能，不调整 Remote Control 或其他设置页的分类，不改变后端接口。

## 审计问题

| 优先级 | 问题 | 修改要求 |
| --- | --- | --- |
| 高 | 窗口宽 1024px 时，两层侧栏挤压内容区，双栏和固定行高造成文字重叠 | 根据内容宽度排版；取消固定行高；长值允许换行 |
| 高 | 首次加载失败仍显示正常、零值；刷新失败未标识旧数据 | 分开加载、未知、成功、数据过期状态；显示更新时间并自动重试 |
| 中 | 顶部和 Basic Status 重复名称、位置、模式、健康、时间等字段 | 每项信息只展示一次；技术标识放入折叠详情 |
| 中 | 左侧多张卡片、右侧单张卡片导致大块留白，摘要时间却被截断 | 改为顺序明确的全宽分区；时间完整展示 |
| 中 | 未配置渠道同时显示 Not Configured 和 Idle | 一个渠道一个状态；未配置渠道折叠；使用现有渠道图标 |
| 中 | 字段仅 12px，标签颜色过浅、全部大写，手机阅读困难 | 使用正文级字号、正常大小写和较深的文字颜色 |
| 中 | Poke 弹窗缺少可访问名称，输入标签和错误提示未正确关联 | 将标题、标签、错误说明关联到实际交互元素 |
| 低 | Poke 按钮位置松散、触摸高度不足，禁用原因不明确 | 放在标题行右侧；触摸目标至少 44px；说明执行中的状态 |

审计覆盖 320、390、1024、1440px 浏览器视口、初次请求失败、刷新失败和弹窗可访问性树。手机宽度模拟不等同于 Android 或 iOS 真机验证。

## 页面结构

1. 运行状态：名称、模式、健康状态、运行时长、启动时间、最近 Poke；标题行提供 Poke，数据自动更新。
2. 当前模型与渠道：模型字段保持完整；已配置渠道直接展示，未配置渠道在折叠区查看。
3. 资源指标：内存、goroutine、heap 对象和 GC 次数；不使用装饰性图表。
4. 技术详情：Endpoint 名称与标识、位置、实例 ID、程序版本、Go 版本。

正常状态使用 Morph 蓝色，并保留文字（2026-09-25 起改为绿色方块，蓝色只表示选中，见 `feat_20260925_console_design_review.md` G2 / D1）；异常和过期状态不依赖颜色单独表达。保留 Morph 的卡片边角样式，去掉大号 hero 和重复摘要。

## 状态规则

- 首次请求完成前不展示占位的正常状态或零指标。
- 首次请求失败显示不可用和错误原因，自动重试，不提供页面内刷新按钮。
- 刷新失败保留上次成功数据，明确标为过期，并保留成功更新时间。
- 切换 endpoint 后不展示前一个 endpoint 的数据；旧请求不能覆盖当前页面。
- Poke 仅在当前状态可用且 awareness 未运行时允许提交；禁用状态有解释。
- 后台刷新不插入占位条造成页面位移，离开页面时清理定时器。

## 验收

- 在 320、390、1024、1440px 及放大字体下，内容无横向溢出、逐字竖排或重叠。
- 短字段在手机上仍可左右排列；长字段自然换行，不使用省略号隐藏时间或版本。
- 每个字段只出现一次，全部原有数据仍可找到。
- 初始错误、刷新错误、重试成功、endpoint 切换和 Poke 禁用状态正确。
- Poke 弹窗具有可访问名称，输入标签与错误提示正确关联，键盘可操作。
- 前端构建通过；不新增前端测试文件。浏览器检查不发送真实 Poke，不改写运行配置。

## 实施记录

- 已将页面改为紧凑状态区、模型与渠道、资源指标和折叠技术详情，删除重复摘要与大号 hero。
- 宽屏使用内容容器查询排列模型和渠道、资源指标；窄内容区保持单列，字段行不再固定高度。
- 未配置渠道折叠，渠道状态合并为单一描述，复用已有渠道图标。
- 保留自动更新、成功更新时间、首次失败和过期数据提示；状态不可用或 awareness 执行时禁用 Poke。
- 请求绑定 endpoint，并用请求序号丢弃切换或卸载后的旧响应。
- 修正共享弹窗自定义标题与 Poke 输入框的可访问属性。保留现有 QDialog 和 QTextarea，用局部指令补足组件未传递到内部元素的属性。
- 补充英文、中文、日文文案，提高标签对比度，按钮触摸高度至少 44px。

验证结果：前端构建及差异格式检查通过。浏览器检查覆盖四种视口、展开技术详情与未配置渠道、1024px 下 200% 字体、首次失败、刷新失败、重试成功、awareness 执行状态以及 Poke 弹窗标签和键盘焦点。没有发送实际 Poke，没有修改服务配置，没有新增前端测试文件。

Endpoint 切换的旧响应保护已进行代码检查；多 endpoint 真机切换、Android/iOS 字体与触摸体验仍需人工走查。

## 走查后调整

- Technical details 使用与其他区域相同的 Morph QCard 边框、边角、标题和内边距，保留默认折叠；展开指示置于标题右侧。
- 删除 Runtime、Overview、Audit 和文件预览中的手动刷新按钮。状态页面由自动更新维护，必要时可使用浏览器重载。检查版本更新和授权续期是业务动作，不属于数据刷新，保留。
- Runtime 与 Overview 保留原有定时更新；Audit 每 15 秒更新可见页面中的最新页，查看历史页时不改变分页；离开页面清理定时器，切换文件后丢弃旧响应。
- 文件预览保留打开、关闭、下载、全屏及预览凭证自动续期，不定时重载嵌入页面，以免中断其中的交互。
- Poke 只保留标题、输入框和发送按钮；关闭由弹窗关闭按钮或桌面窗口承担。移除重复说明、可见输入标签、常驻大小限制和字节计数，保留辅助技术使用的输入标签。
- 输入超限和发送错误才显示提示，原有字节限制和提交校验保持不变。
